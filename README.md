# Customer-Engagement-Product-Utilization-Analytics-for-Retention-Strategy 
### [Download Report](./Customer Engagement Research Project.docx) 
Analyzing 10,000 bank customers, this study finds engagement—not balance or salary—drives churn. Inactive members churn 2x more than active ones despite similar balances. Churn peaks at 3-4 products, not fewer. High-balance but inactive customers churn 3x more, urging engagement-driven, not demographic-based, retention strategy.
